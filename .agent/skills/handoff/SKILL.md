# Agent Handoff Skill

## Purpose

Make feature state recoverable by another agent without conversation history.

## Update `plan.md` with

### Progress
What is complete, in order.

### Discoveries
Only material findings that can affect scope, implementation, or future phases.

### Decision Log
What changed, why, and which source supports the decision.

### Remaining Work
Exact unfinished task IDs and blockers.

### Validation
Commands/tests run and relevant outcomes.

### Outcome
Final status and known limitations.

## Rule

Do not rely on a verbal handoff or chat memory for material project state.
