# ADR-007 — Wallet Funding Scope

## Status
Accepted

## Decision
The current payment scope includes the internal wallet and wallet funding via Bravo, CashiPay, and Bank Transfer with manual bank-transfer review. The current requirements do not establish wallet balance as the payment method for visa/service applications, so feature plans do not implement that linkage.

## Evidence
The current requirements source explicitly records wallet funding and separately notes that paying service applications from wallet balance is not decided.
